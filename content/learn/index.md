## 1. 核心图解：代理三要素的职责分工

```
+-----------------------------------------------------------------------+
| 1. 图形界面外壳 (GUI Client: 例如 Clash Verge Rev / v2rayN)           |
|    - 职责: 提供可视化按钮、读取本地配置、展示节点列表、控制开关          |
+-----------------------------------------------------------------------+
                                  │ (内部进程间调用 / API 控制)
                                  ▼
+-----------------------------------------------------------------------+
| 2. 协议路由核心 (Kernel / Core: 例如 Mihomo / Xray-core / sing-box)   |
|    - 职责: 监听本地端口(7890)、执行分流规则匹配、对数据包进行加密与伪装    |
+-----------------------------------------------------------------------+
                                  │ (加密数据流通过物理光纤与海底光缆)
                                  ▼
+-----------------------------------------------------------------------+
| 3. 远端服务节点 (Node / Airport: 位于香港、日本、美国等地的物理服务器)     |
|    - 职责: 接收客户端发来的加密流量，将其解密后发送给目标网站 (如 Google) |
|            并将目标网站返回的数据再次加密转发回你的电脑                |
+-----------------------------------------------------------------------+
```

### 常见新手认知误区
- **误区一：“我在 App Store 花钱买了解密工具，为什么打开还是上不了网？”**
  - 解答：软件商店收取的仅是“软件开发者的代码授权费”。软件本身就像一辆空车，车里没有汽油（没有配置节点服务器地址），当然无法行驶。你必须向车内添加节点配置（自建或购买合规服务）。
- **误区二：“我买了一家很贵的机场，是不是随便下载什么客户端网速都一样快？”**
  - 解答：不一定。劣质或老旧的客户端（未优化多线程、未开启硬件加速、DNS 严重延迟）会成为本地性能瓶颈，拖累优质节点的实际吞吐表现。

## 2. 必须掌握的三大核心模式区别

在所有客户端中，你都会看到以下三种工作模式，请根据场景严格选择：

| 代理模式 | 流量路由行为 | 适用典型场景 | 新手避坑提示 |
| :--- | :--- | :--- | :--- |
| **规则模式 (Rule)** | **智能分流**：国内域名直接连，国外域名走代理 | **日常 99% 时间推荐使用** | 兼顾国内 App 速度与国外访问，互不干扰 |
| **全局模式 (Global)** | **全量接管**：所有流量一律强行塞进代理节点 | 仅限临时排查分流规则故障 | 极易导致微信、网易云等国内应用报封号或严重卡顿 |
| **直连模式 (Direct)** | **完全绕过**：所有请求一律不通过节点，直接连接 | 临时彻底停用代理测试本地网速 | 相当于未开启代理状态 |

## 3. 从零开始的新手成长五大里程碑

```
[里程碑 1: 概念建立] ──> 理解客户端、核心与节点的区别，分清系统代理与 TUN
             │
[里程碑 2: 工具安装] ──> 在本机安全下载安装官方客户端，确保托盘常驻无报错
             │
[里程碑 3: 订阅导入] ──> 正确识别 YAML/Base64 链接，完成首个订阅节点拉取
             │
[里程碑 4: 分流验证] ──> 开启规则模式，用 IP 测试工具核验国外走代理、国内走直连
             │
[里程碑 5: 基础自救] ──> 掌握关闭客户端后断网的恢复方法，能看懂端口冲突报错
```

## 4. 商业计费与流量常识防坑账本

购买第三方服务时，必须看清计费背后的算术陷阱：

1. **“不限流量”的神话**：物理带宽是有真实成本的。宣称“超低价且不限流量”的服务商，往往在后台实施严格的公平使用原则 (FUP)，一旦你下载大文件，立即触发恶性限速至 128Kbps。
2. **节点倍率的真实消耗**：连接 3.0x 倍率的节点看了一部 10GB 的 4K 电影，实际账户余额将被扣除 30GB 流量。日常使用建议优选 1.0x 或 0.5x 节点。
3. **周期重置与清零**：明确套餐流量是在“每月 1 号”清零，还是在你“购买日”按 30 天周期重置，避免月底流量突发归零导致断网。
