## 1. 我们收集与不收集的信息

### 1.1 我们绝对不收集的信息
- **账号与密码凭证**：本站全站内容完全开放免费阅读，不需要用户注册账号、输入手机号或提供个人实名信息；
- **订阅链接与 Token**：本站绝不提供任何需要将用户个人专属订阅 URL 上传至服务端的在线转换服务，杜绝 Token 泄漏风险；
- **网络访问流量日志**：本站仅为技术资讯与指南展示平台，不运行任何中转代理节点，根本不具备接触用户代理流量的技术途径。

### 1.2 我们可能接触的匿名技术数据
- **标准 Web 访问日志**：当您访问本站时，托管服务器或 CDN（如 Cloudflare）会自动记录常规的匿名 HTTP 请求日志（包含匿名化 IP、请求时间戳、浏览器 User-Agent、请求页面路径），该数据仅用于防御 DDoS 恶意攻击与统计全站 PV/UV 流量。
- **本地存储（Local Storage）**：本站仅在您的浏览器本地存储中保存一个用于记录“日间模式 / 夜间深色模式”偏好的键值（如 `vitepress-theme-appearance`），该数据完全驻留于您的本地设备，不会回传至任何服务器。

本站文章中包含指向开源软件官方代码仓库（如 GitHub）、官方应用商店（如 Apple App Store）以及经过核验的第三方机场服务商官方网站的超链接。

当您点击这些超链接离开本站并进入第三方网站时：
- 本隐私政策将不再适用；
- 第三方网站拥有其完全独立的隐私政策与数据收集规则；
- 我们强烈建议您在向任何第三方网站提供邮箱或付款信息前，仔细阅读其官方隐私条款。
