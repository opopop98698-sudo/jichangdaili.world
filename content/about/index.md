## 1. 我们的使命与价值观

在当今网络代理与翻墙工具生态中，充斥着大量虚假的“全绿低延迟截图”、黑心跑路机场的三年付大额收割陷阱、以及被篡改注入后门木马的“免翻版”客户端安装包。

本站创立的核心初衷，是**为广大开发者、跨境科研人员、外贸企业及数字游民提供一套具备工业级严肃度、数据可复现、安全透明的技术参考指南**：

1. **坚持官方正版与开源溯源**：全站所有客户端推荐均认准官方 GitHub Releases、App Store 或开发者权威源，提供 SHA-256 哈希比对指引，绝不提供任何第三方修改版、加壳版或内置节点的灰产安装包。
2. **坚持晚高峰真实物理压测**：彻底打破单次 ICMP 假绿欺骗，固定在 20:30 - 22:30 恶劣网络拥堵期，通过端到端 HTTP GET 首字节延迟（TTFB）与多线程大文件压测呈现真实可用速率。
3. **坚持商业推广透明度隔离**：所有带有返利属性的外链均显式标明 `rel="sponsored nofollow noopener"`，评测打分与商业赞助严格分离，绝不接受“付费删差评”或“虚假夸大测速”。

## 2. 团队组成与专业背景

本站内容与测试管线由多位具备深厚计算机网络与信息安全背景的工程师共同维护：

- **网络协议审计组**：负责跟踪 Xray-core、Mihomo (Clash.Meta)、Sing-box 核心协议演进（Reality、Hysteria 2、TUIC v5），编写自动化抓包与加密特征分析脚本。
- **客户端平台适配组**：覆盖 Windows、macOS (Apple Silicon/Intel)、Android、iOS 及 OpenWrt 软路由环境，负责编写跨平台特权驱动（Wintun / utun）排错与安装配置指南。
- **基准测试与监控组**：在全国三网骨干节点（中国电信千兆、中国联通千兆、中国移动 500M）常态化挂载自动化探针，持续监控 42 家主流机场的在线率 SLA 与流媒体/AI 解锁纯净度。

## 3. 核心准则与行为红线

- **红线 1**：坚决不在本站提供任何未经核验的破解版或带有提权后门的安装包。
- **红线 2**：所有涉及佣金推广的卡片，必须显式标注商业披露，且用户购买成本绝不会因推广链接而增加。
- **红线 3**：严厉谴责并定期曝光超长周期（三年付/永久无限流量）杀猪盘与恶意跑路品牌。
